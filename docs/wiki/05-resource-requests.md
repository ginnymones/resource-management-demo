# Resource Requests

Resource requests are how you formally ask to cross-utilize associates from other teams. The request goes through an approval workflow before the associate is committed.

*Available to: POC, Manager, Senior Leader, Admin*

## Submitting a Request

After selecting associates from the Matchmaker:

1. You'll see a **Request Intake Form** with the selected associates pre-populated
2. Fill in the required fields:
   - **Project Name** — A short name for your project (max 100 characters)
   - **Required Skills** — The skills you need (pre-filled from your search)
   - **Start and End Dates** — When you need the associate(s)
   - **Hours Per Day** — How many hours per day you need (0.5 to 7.5)
   - **Target Process** — Which process the work falls under
   - **Business Justification** — Why this cross-utilization is needed (max 1000 characters)
3. Click **Submit Request** or **Save as Draft**

## Request Statuses

| Status | Meaning |
|--------|---------|
| **Draft** | Saved but not submitted — you can edit and submit later |
| **Pending** | Submitted and waiting for the associate's manager to decide |
| **Approved** | All requested associates are approved |
| **Partially Approved** | Some associates approved, some rejected |
| **Active** | The cross-utilization period has started |
| **Completed** | The end date has passed |
| **Rejected** | All requested associates were rejected |
| **Cancelled** | You cancelled the request before it was decided |

## Managing Your Requests

Go to **My Requests** from the sidebar to see all your submitted and draft requests.

- **Filter by status** — Use the dropdown to show only specific statuses
- **Click a request** — Opens the full detail view
- **Edit a draft** — Click the "Edit & Submit" button, or click the draft card to be taken directly to the editable form
- **Delete a draft** — Open the draft and click "Delete Draft" at the bottom

## The Approval Process

When you submit a request:
1. It routes to the **manager of each requested associate's team**
2. The manager receives a notification and sees it in their Pending Approvals panel
3. They can:
   - **Approve** — The associate's bandwidth is reduced to reflect the commitment
   - **Reject** — They must provide a reason (20+ characters). You'll receive alternate suggestions.
   - **Partially approve** — Approve some associates, reject others
4. If the manager doesn't act within 48 hours, they receive a reminder
5. After 3 reminders with no action, the request escalates to the next Senior Leader

## After Approval

- The request status moves from Approved → Active on the start date
- The request moves to Completed on the end date
- The associate's bandwidth is restored when the commitment ends
