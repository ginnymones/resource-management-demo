# Roles & Permissions

The platform has five roles, each with different levels of access. Your role is assigned by an administrator based on your position in the organization.

## Role Summary

| Role | Description | Typical Users |
|------|-------------|---------------|
| **Associate** | Logs their own working hours | L3 individual contributors |
| **SME** | Views capacity data and org roster | L3/L4 subject matter experts who need visibility |
| **POC** | Can search for and request associates | L4+ points of contact who coordinate resourcing |
| **Manager** | Can approve/reject requests for their team | Team leads and managers |
| **Senior Leader** | Can approve across teams and override decisions | L6+ leaders |
| **Admin** | Full platform access including configuration | Platform administrators |

## What Each Role Can Do

### Associate
- ✓ Log their own time entries
- ✓ View their own timesheet history
- ✓ Edit/delete today's entries
- ✗ Cannot view other people's data
- ✗ Cannot access Climate, Roster, or Matchmaker

### SME
- ✓ View Resource Climate (calendar + table)
- ✓ Browse the Roster
- ✗ Cannot use the Matchmaker
- ✗ Cannot submit resource requests

### POC
- ✓ Everything an SME can do, plus:
- ✓ Use the Matchmaker to search for associates
- ✓ Submit cross-utilization requests
- ✓ Manage their own drafts and requests

### Manager
- ✓ Everything a POC can do, plus:
- ✓ See pending approval requests
- ✓ Approve or reject requests for their team's associates
- ✓ Use Manager and Associate calendar views

### Senior Leader
- ✓ Everything a Manager can do, plus:
- ✓ Approve requests across all teams
- ✓ Override existing approval/rejection decisions (with justification)

### Admin
- ✓ Everything a Senior Leader can do, plus:
- ✓ Create and manage user accounts
- ✓ Configure processes and complexity factors
- ✓ Import and export data (CSV)
- ✓ Access the Efficiency Tracker for bulk time entry

## How Roles Are Assigned

Roles are assigned by an Admin through the Admin panel → User Management tab. When a new account is created, it defaults to SME. The Admin can change the role at any time — the change takes effect on the user's next page navigation.
