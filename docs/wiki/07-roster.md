# Roster

The Roster is a searchable directory of all associates in the organization. It gives you quick access to who's on which team, their skills, their manager, their current activity status, and more.

*Available to: SME, POC, Manager, Senior Leader, Admin*

## Browsing the Roster

The Roster page shows a paginated table (25 associates per page) with:

| Column | Description |
|--------|-------------|
| Name | Associate's full name or login ID (toggle-able) |
| Team | Which program they belong to |
| Level | Job level (L3, L4, L5, etc.) |
| Site | Office location code (NYC1, AUS2, DUB3) |
| Job Title | Their official title |
| Skills | Top skills (up to 3 shown, with a "+N" badge for more) |
| Manager | Who they report to (name or login, based on toggle) |
| Status | Current activity status (color-coded badge) |
| Activity | Specific sub-activity detail |

## Activity Status

Each associate's current status is shown as a color-coded badge:

| Status | Color | Meaning |
|--------|-------|---------|
| Production | 🟢 Green | Currently doing production work |
| Meeting | 🔵 Blue | In a non-production meeting |
| Break | 🟡 Yellow | On lunch/dinner/coffee break |
| Leave | 🟣 Purple | On sick/vacation/casual leave |
| Not on shift | ⚫ Gray | Not currently working |

The **Activity** column shows the specific sub-activity:
- **Meeting types**: Dry Queue, New Workflow Training, One-on-one Meeting, Team Meeting, Shadow Session, etc.
- **Production types**: Specific process name (e.g., "Video", "STL", "CPB") or "Confidential"

## Display Toggle

Use the **Name/Login** toggle to switch between:
- **Name view** — Shows full names (e.g., "Avery Thorne") and manager names
- **Login view** (default) — Shows employee login IDs (e.g., "athorne") and manager logins

## Searching

Use the search box to find associates by **name** or **employee login**. The search is case-insensitive and matches partial text.

## Filters

| Filter | Description |
|--------|-------------|
| Team | Show only associates from a specific team/program |
| Manager | Show only associates who report to a specific manager |
| Skill | Show only associates who have a specific skill |
| Proficiency | Minimum proficiency level (Expert, Proficient, or Trained) |
| Status | Filter by current activity status (Production, Meeting, Break, Leave, Stop) |

When both Skill and Proficiency filters are active, results show associates who have the selected skill at or above the selected proficiency level.

## Selecting Associates & Requesting Cross-Utilization

You can select one or more associates directly from the Roster to request cross-utilization:

1. Click the **checkbox** next to an associate's name (this won't navigate away from the page)
2. Use the **header checkbox** to select/deselect all visible associates
3. A sticky bar appears at the bottom showing how many are selected
4. Click **"Request Cross-Utilization"** to go directly to the request form with the selected associates pre-loaded

This is a shortcut — you don't need to use the Matchmaker first if you already know who you want.

## Skills Tooltip

The Skills column shows up to 3 skills per associate. If they have more, a "+N" badge appears. **Hover** over the "+N" badge to see all remaining skills in a tooltip.

## Sorting

Click any column header with the ↕ icon to sort:
- **Name** — Alphabetical by name or login
- **Team** — Alphabetical by team name
- **Level** — By job level
- **Site** — By location code
- **Manager** — Alphabetical by manager name or login
- **Status** — Alphabetical by status

Click again to reverse the sort direction.

## Clicking an Associate

Click any row to navigate to that associate's full profile page, which shows their complete skills, training history, bandwidth, and deployment history.

## Total Count

The total number of matching associates is shown in the top-right of the filter bar (e.g., "228 associates").
